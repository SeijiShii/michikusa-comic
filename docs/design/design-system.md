## 1. デザイン原則（コンセプト → 視覚の翻訳）

1. **道草の「ゆるい発見」を主役に** — UI は黒子。写真と 4 コマが画面の主役で、装飾は控えめ（concept「作品性より気軽さ・面白がり」）
2. **手描きの温かみ** — 角丸・丸ゴシック・紙の質感で「気軽に落書きする」感覚。プロ制作ツールの硬さを避ける（ターゲット「絵心はない一般の人」）
3. **急かさない・煽らない** — 数字バッジ・連続記録・赤い通知ドットを多用しない。穏やかな配色（charter §2.2 中毒/競争回避）
4. **待ち時間も心地よく** — AI 生成の数十秒は「散歩の途中」の比喩で楽しく待たせる（O45 進捗体験、concept §3 NFR「待ち時間 UX を丁寧に」）
5. **片手・屋外で使える** — 散歩中のスマホ片手操作前提。大きめタップ領域・高コントラスト・明るい屋外でも読める

## 2. カラートークン（意味名 + 値 + 用途）

> ベースは「クラフト紙 + くすんだ草色・空色」。彩度を抑えた温かみのあるパレット。ダークモードは v2。

| トークン | 値（light） | 用途 |
|---|---|---|
| `--bg-base` | `#F7F3EC`（生成り/クラフト紙） | アプリ背景 |
| `--bg-surface` | `#FFFFFF` | カード・コマ枠の面 |
| `--bg-sunken` | `#EFE9DE` | 入力欄・くぼみ |
| `--text-primary` | `#3A352E`（焦茶、真っ黒を避ける） | 本文・見出し |
| `--text-secondary` | `#7A7264` | 補助テキスト・キャプション |
| `--border-soft` | `#E2DACC` | 境界・区切り |
| `--brand-primary` | `#7E9B6E`（くすんだ草色/sage） | 主アクション・選択状態 |
| `--brand-primary-ink` | `#FFFFFF` | 主ボタン上の文字 |
| `--accent-sky` | `#8FB8C9`（くすんだ空色） | アクセント・リンク・進捗 |
| `--accent-warm` | `#E0A66B`（陽だまりの橙） | 強調・お気に入り（控えめに） |
| `--state-success` | `#7E9B6E` | 完了 |
| `--state-warning` | `#D9A441` | 注意（無料枠など） |
| `--state-danger` | `#C77B6B`（くすんだ朱、警告色も穏やかに） | 削除・エラー |

> コントラスト: `--text-primary` × `--bg-base` は WCAG AA 確保。主ボタンは sage × 白で可読。

## 3. タイポグラフィ

| 役割 | フォント方針 | サイズ/行間 |
|---|---|---|
| 見出し | やわらかい丸ゴシック（例: Zen Maru Gothic / M PLUS Rounded 1c。Web フォント） | 20–28px / 1.4 |
| 本文 | 同系丸ゴシック or システム丸ゴシック | 15–16px / 1.7 |
| キャプション | 同上・`--text-secondary` | 13px / 1.5 |
| 4 コマ内セリフ | 手書き風 or 丸ゴシック（コマ合成時、可読性優先） | 可変（アプリ側合成、[論点-001]） |

- スケール: 13 / 15 / 16 / 18 / 20 / 24 / 28（モバイル基準）
- Web フォントは丸ゴシック 1 種に絞りロード軽量化（PWA 初期表示配慮）

## 4. 形・影・余白

- **角丸**: `--radius-sm 8px` / `--radius-md 14px`（カード）/ `--radius-lg 22px`（モーダル・主ボタン、丸み強め）
- **影**: 控えめ・拡散。`--shadow-card: 0 2px 12px rgba(58,53,46,0.06)`。硬いドロップシャドウは使わない
- **余白スケール**: 4 / 8 / 12 / 16 / 24 / 32 / 48（8 基準）。屋外片手操作のためタップ領域は最小 44×44px

## 5. コンポーネント（基本形）

- **ボタン**: 主=sage 塗り+白文字+`radius-lg`、副=境界線のみ、文字ボタン=下線なし色変化。タップ領域 44px+
- **カード（4 コマ/作品）**: 白面 + `radius-md` + `shadow-card`。写真/コマが主役、メタ（日付/エリア）は控えめキャプション
- **チップ**: エリア/タグ用、`bg-sunken` + 角丸 pill
- **入力**: `bg-sunken` + 内側余白広め、フォーカスで sage 境界
- **進捗（生成中）**: O45 準拠。素のスピナーでなく「描いています…」等の実段階文言 + 軽いゆらぎ。嘘進捗・わざと遅延は NG
- **入口の「これは何？」導線（O41）**: トップ/ギャラリー入口に 1 行リード文（例: 「散歩で見つけた風景を、4 コマにして残すアプリ」）を優先配置。収まらない画面では丸付き「?」インフォボタン + 軽量モーダル（内容は concept §1 由来）
- **空状態**: 自作 SVG イラスト（line-art の散歩道/カメラ/猫など、テーマ色追従）+ やさしい誘導文

## 6. ボイス & コピー（O38 準拠）

- **トーン**: 友達がそっと教えてくれるような、やわらかい敬体寄り。煽らない・急かさない
- **NG（技術用語）→ 言い換え例**:
  - 「生成」→「4 コマにする / 描く」
  - 「アップロード」→「写真をえらぶ」
  - 「エクスポート/書き出し」→「画像にして保存」
  - 「レンダリング/プレビュー」→「できあがり / ためし表示」
  - 「エラー」→「うまくいきませんでした。もう一度ためしてみてください」
- **エラー方針**: 原因を責めず、次の一歩を示す。DB 内容/技術詳細は出さない（SEC-002 PII とも整合）
- 詳細な対話校正は Phase 4 で `/flow:wording`（O42）

## 7. アイコン & イラスト & ブランドマーク戦略

- **UI アイコン**: OSS 標準セット（例: lucide）。**絵文字は使わない**（環境依存で崩れる、O38）
- **イラスト**: 空状態/ヒーロー/装飾は自作 SVG line-art（散歩道・カメラ・足あと・猫・季節モチーフ）、テーマ色追従
- **ブランドマーク（PWA 必須、O56）**: 単一 SVG ソース「道草マーク」（散歩道 or 4 コマ枠 + 草の芽を丸く図案化、sage 主色）から派生:
  - `public/favicon.svg`（ソース）+ `favicon.ico` + `apple-touch-icon.png`(180²) + `icon-192/512.png` + `icon-maskable-512.png` + `manifest.json` icons + HTML head wiring
  - 生成は `scripts/gen-favicon.js`（sharp + to-ico）。**絵文字 favicon は NG**。実装は Phase 3（scaffold 後）
- 写実ラスターは使わない（テーマと不整合 + 要キー）

## 8. レビュー基準（Phase 3 視覚レビューで使う）

- 写真/4 コマが画面の主役か（UI が出しゃばっていないか）
- 配色が穏やかで煽っていないか（赤通知ドット乱用・数字バッジ過多がないか）
- 角丸・余白・丸ゴシックで温かみが出ているか
- 生成中画面が O45 進捗体験になっているか（素スピナー/フリーズでないか）
- 入口で「これは何のアプリか」が初見で分かるか（O41）
- 課金導線で金額+対価が CTA より前に明示か（O43、export 画面）
- 全ルートにアプリ内導線があるか（O55、特に /legal/* /account）
- ユーザー向けコピーに技術用語がないか（O38）
